# 学习休息倒计时

这是一个本地 macOS 原生小应用：

- 启动后先进入学习倒计时，默认 20 分钟。
- 到点后弹出全屏休息倒计时，默认 2 分钟。
- 可以在菜单栏 `设置...` 中修改学习时间（1-240 分钟）和休息时间（1-60 分钟），仅支持整数分钟；保存后从下一轮对应计时开始生效。
- 可以在菜单栏 `学习统计...` 中查看学习概览、近 53 周活动和一天中的学习分布。
- 学习倒计时运行且电脑未睡眠时，会自动记录真实学习时间，包括未完成的学习轮次。
- 休息界面会覆盖所有桌面/Space，并显示剩余时间和结束休息时间。
- 休息期间可以点击 `熄屏`，或在休息窗口按 `Command + Shift + D`，关闭全部显示器；本轮剩余休息结束后自动亮屏，显示 `继续学习` / `停止学习`。
- 熄屏前会显示 `准备熄屏…`，等待按键和鼠标松开、连续静置 1 秒后再关闭显示器；等待期间有输入会重新计时，超过 10 秒则取消并允许重试。
- 熄屏状态结合系统屏幕休眠／唤醒通知判断，避免显示器查询状态滞后或虚拟显示器导致误报失败、重新置顶休息窗口。
- 熄屏后提前按键或移动鼠标亮屏，会继续剩余休息；合盖或手动让电脑睡眠会取消本次自动亮屏，沿用原有睡眠恢复规则。
- 每轮休息最多可以使用一次 `1分钟后休息`，延后结束后仍会进入完整休息。
- 休息和延后期间无法从菜单直接开始、停止学习或退出应用；`立即开始休息` 只会提前进入本轮完整休息，不会恢复延后机会。
- 休息开始后的前 30 秒不能跳过；之后只有持续按住紧急跳过按钮 5 秒，才能提前结束休息。
- 紧急跳过每天最多成功使用 2 次、每周一至周日最多 6 次；设置窗口会显示今日和本周用量。
- 未完成的休息会保存在本机；退出、异常终止或重新打开应用后仍需完成剩余休息。
- 倒计时结束后不会自动消失，会显示 `继续学习` 和 `停止学习`。
- 提前结束休息后也会显示 `继续学习` 和 `停止学习`，应用不会退出。
- 点击 `继续学习` 后按照设置的学习时间进入下一轮计时。
- 点击 `停止学习` 后停止计时，应用会留在菜单栏显示 `已停止`。
- 只有系统睡眠或所有在线显示器都关闭时才累计无屏幕休息；笔记本合盖但外接显示器仍亮时不会累计。
- 所有显示器关闭时间不足本轮休息时，重新亮屏后继续剩余休息；达到休息时长后自动开始新一轮学习。
- 默认在周三、周日 14:00 自动切换为 `已停止`；如果保持该状态，17:00 自动开始完整学习周期。
- 会议提前结束时可以随时手动开始学习，同一场会议不会再次停止，也不会在 17:00 重置当前倒计时。
- 会议日程触发时会取消正在进行的学习或休息，不消耗紧急跳过额度；该功能可以在设置中关闭。

## 使用

### 直接下载安装

在 [GitHub Releases](https://github.com/zhoujin033/FocusBreakTimer/releases/latest) 下载 `.dmg`，打开后将“学习休息倒计时”拖到“Applications（应用程序）”。也可以下载 `.zip` 后解压安装，无需编译或安装开发工具。安装包支持 macOS 13 及以上，同时兼容 Apple 芯片和 Intel Mac。

升级前先退出旧版再替换 App，学习记录和设置会保留。当前安装包尚未使用 Apple Developer ID 签名或苹果公证，首次打开可能被 macOS 拦截；确认来自本仓库后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中允许打开，不要关闭系统安全保护。

### 当前版本

版本 `3.7.3` 将标题、圆环和主按钮作为整体居中，平衡结束选择界面的上下留白；背景与次按钮改为中性炭灰，圆环与主按钮使用柔和绿色，去除偏蓝的底色。两个状态仍共用布局和按钮样式。

当前构建号为 `36`，已撤回后续两次外观尝试，恢复完整的 `3.7.3` 界面；学习设置、统计记录与计时功能保留。

版本 `3.7.2` 统一休息倒计时与结束选择的视觉样式：圆环、背景和文字位置保持一致，左右按钮使用相同尺寸、间距、圆角、字体和低饱和配色；结束时在原位置切换为 `继续学习` / `停止学习`，不再突然出现亮绿、亮红按钮。延后休息、熄屏、紧急跳过及结束后的操作规则保持不变。

版本 `3.7.1` 将固定会议日程调整为每周三、周日 14:00-17:00，设置中的开关继续有效。升级时会同步调整旧日程的待恢复时间，并取消已不适用的周二恢复事件。

版本 `3.7` 新增休息时长设置，默认休息 2 分钟。修改设置不会重置当前学习或休息，也不会缩短已经延后的本轮休息；升级或重新打开应用时，未完成的休息仍按该轮原有时长恢复。菜单里的 `立刻休息`、圆环进度、结束休息时间和熄屏后的自动亮屏均使用本轮实际休息时长。

版本 `3.6.1` 修复熄屏后因松键或触控板后续输入立即亮屏的问题。熄屏按钮在按钮内松开后触发；按钮与快捷键都会等待输入结束和 1 秒静置，准备及熄屏期间暂停窗口置顶。快捷键只在休息界面生效，熄屏不消耗紧急跳过次数，也不计入学习时间。电脑保持运行时会在剩余休息结束后请求亮屏；如果系统已锁屏，解锁后才能看到结束选项。熄屏失败会在原休息界面提示并允许重试；自动亮屏失败时，手动亮屏仍会显示结束选项。

版本 `3.5.1` 修复休息界面的外接显示器适配：根据每块屏幕的尺寸独立绘制，在缩放变化时刷新，适配较小的逻辑显示尺寸，并清理断开显示器后的旧窗口。修复内容和验证范围见 [外接显示器修复说明](FIX_EXTERNAL_DISPLAY.md)。

从源码包升级时，先退出旧版应用，再双击 `BuildAndRun.command`，脚本会在 Mac 上构建并启动新版。需要安装 Xcode Command Line Tools；如果缺少工具，可在终端运行 `xcode-select --install` 后重试。

双击这个应用：

```text
学习休息倒计时.app
```

应用启动后会出现在菜单栏，显示类似 `学习 20:00`。菜单里可以立刻开始休息、重新开始学习、停止学习、打开设置，或退出应用。

版本 `3.5` 使用新的独立应用标识，避开 macOS 26 Control Center 可能残留的跨应用菜单栏关联；关闭 ChatGPT 或其他应用的菜单栏项目不会再同步隐藏倒计时。升级时会自动迁移学习时间、会议开关、紧急跳过额度和未完成休息，原有学习历史也会继续使用。

学习统计从版本 `2.9` 首次运行后开始记录，无法补算旧版本中的学习时间。版本 `3.1` 及后续版本的概览会显示累计学习时间、单日峰值、最长单次学习以及连续学习天数；学习活动热力图覆盖最近 53 周，可以切换 `每日`、`每周` 和 `累计` 三种统计方式。每日模式按日期显示学习强度；每周和累计模式使用 7 级格子柱，并在悬停时显示整周提示。

热力图从星期一到星期日排列。点击任意过去或今天的日期，可以进入日视图查看 24 小时分布和每段学习记录。每天累计学习达到 6 小时会记为一个连续学习日；如果今天尚未达到 6 小时，当前连续天数会暂时保留到昨天，并在今天结束后重新判断。

学习历史只保存在本机：

```text
~/Library/Application Support/local.codex.FocusBreakTimer/study-history.json
```

可以在 `设置...` 中查看紧急跳过额度、开关固定会议日程，以及清空全部学习记录。

应用只会在你点击菜单栏里的 `退出应用` 后结束运行；未完成休息时该命令会暂时禁用。

当前版本不会自动设置开机启动，也不会上传学习记录；只有你手动启动后才会开始循环。

## 重新构建

```sh
./build.sh
```

构建完成后会生成：

```text
学习休息倒计时.app
```

## 打包发布

在 Mac 上构建同时支持 Apple 芯片和 Intel 的安装包：

```sh
UNIVERSAL_BUILD=1 bash build.sh
bash scripts/package_app.sh
```

DMG、ZIP 和校验文件生成在 `build/release/`，不提交到源码仓库。更新 `Info.plist` 和 `RELEASE_NOTES.md` 后，推送与应用版本一致的 `v版本号` 标签，GitHub Actions 会自动测试、构建并发布到 Releases；全部文件上传成功后才公开发布。

## 等待长任务

仓库提供 `scripts/wait_for_process.sh`，可以在一次调用中等待后台任务结束，避免调用方反复轮询。脚本读取 PID 文件、监控日志更新时间，并分别报告正常结束、等待超时和日志停滞：

```sh
./scripts/wait_for_process.sh \
  --pid-file build/task.pid \
  --log-file build/task.log \
  --max-wait 3600 \
  --stale-after 300
```

最终状态会写入默认的 `build/task.pid.wait-status`；可以使用 `--status-file` 指定其他位置。`--max-wait 0` 或 `--stale-after 0` 可以分别停用对应限制。
